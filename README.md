Ember Pact — a duel of elemental cards against Mira, the Ember Witch. Ember burns Thorn, Thorn drinks Tide, Tide douses Ember. Play one card a round, chain the same element for +2, spend Pact cards to heal, ward, surge or snatch, and read Mira's tells to counter her. First to 0 HP loses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play in desktop Chrome. No build step, no network — the game is static files under `game/`.
